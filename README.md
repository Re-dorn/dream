# 云海步道 · Cloudwalk

一条沿着云海延伸的蓝砖步道，右边是白色楼群和密集的招牌，左边的云海里升起两公里高的入道云。
这是 Dream 项目镜头 1 的实时网页版，场景完全用代码搭建（three.js），在浏览器里直接打开就能看。

**在线看：** https://lyreyja.com/Re-dorn-cloudwalk/

## 画风

- **原样**：PBR 材质 + 天空环境光 + Khronos PBR Neutral 色彩变换 + 太阳阴影
- **像素**：低分辨率渲染 + 深度 / 法线描边 + 有限色阶（像素大小 2–8 可调）
- **三渲二**：卡通材质 + 描边 + FXAA

## 操作

| | 电脑 | 手机 / 平板 |
|---|---|---|
| 镜头 1 / 等距俯视 | 拖动旋转 · 滚轮缩放 · 右键平移 | 单指旋转 · 双指缩放和平移 |
| 自由漫游 | 拖动转头 · WASD / 方向键移动 · E 或空格上升 · Q 下降 · Shift 加速 · 滚轮调速度 | 左下摇杆移动 · 拖动转头 · ▲▼ 升降 |
| 快捷键 | 1 2 3 切换画风 · V 切换视角 | |

## 文件

- `index.html`：整个页面（招牌、海报贴图已内嵌）
- `three.module.min.js`：three.js r170（MIT 许可，见 `THREE_LICENSE.txt`）；如果它加载失败，页面会改从 cdnjs / unpkg / jsDelivr 加载

需要支持 WebGL2 的浏览器，并开启显卡加速。
